# Software Quotation Management System

A web-based application for creating and managing software quotations.

## Live Demo

https://quotation-system-six-tawny.vercel.app

## Features

- Supabase Authentication Login
- Create Quotation
- Add Multiple Products
- Automatic GST Calculation
- View Quotations
- Edit & Delete Quotations
- Download PDF
- Search Quotations

## Tech Stack

- React (Vite)
- JavaScript
- Supabase
- Vercel
- GitHub

## Installation

```bash
npm install
npm run dev
```

## Environment Variables

Create a `.env` file:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## Deployment

- GitHub Repository
- Vercel Hosting
- Supabase Database
